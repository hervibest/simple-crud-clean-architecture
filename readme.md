A simple CRUD application built with **Go Fiber**, implementing **Clean Architecture** and **Dependency Injection** principles. This project is designed for an online course management system, utilizing:

- **Fiber**: High-performance web framework for Go
- **GORM**: ORM library for Golang
- **PostgreSQL**: Relational database for data persistence
- **Redis**: In-memory data store for memory based DB
- **FFmpeg**: For media processing needs

The Clean Architecture implementation is inspired by the repository of **Eko Khannedy (Programmer Zaman Now)**, which can be found [here](https://github.com/khannedy/golang-clean-architecture).

## Features

- Clean Architecture structure
- Easy-to-use Dependency Injection
- Course management APIs (Create, Read, Update, Delete)
- Redis integration for authentication database
- FFmpeg support for multimedia processing
